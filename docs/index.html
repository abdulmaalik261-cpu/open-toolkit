open-toolkit
Tools Install GitHub

Four small tools. One install. Nothing phones home.

open-toolkit is a single CLI you run on your own machine — diagram a codebase, sign a PDF, laugh at an over-engineered FizzBuzz, and turn a document into Markdown. No account, no server, no subscription. 

$ pip install open-toolkit
$ toolkit diagram ./my-app -o architecture.md
# wrote architecture.md
$ toolkit doc2md report.pdf -o report.md
Wrote report.md

The four commands

01

toolkit diagram

Walks a Python codebase and works out which local modules import which others, then emits a Mermaid diagram you can drop straight into a README or a Claude artifact. Ships as a Claude Skill too, so an agent can call it directly. 

$ toolkit diagram ./my-app -o architecture.md
02

toolkit sign

A self-hosted e-signature tool. Stamp a typed signature or an image of your real one onto a PDF at exact coordinates — entirely on your own disk, nothing uploaded anywhere. 

$ toolkit sign info contract.pdf
$ toolkit sign apply contract.pdf --page 1 --x 400 --y 80 --text "Jane Doe"
03

toolkit fizzbuzz

FizzBuzz rebuilt with abstract factories, a strategy registry, and a dependency-injection container — all so it can still print "Fizz" when it sees a multiple of three. A working satire of over-engineering. 

$ toolkit fizzbuzz 1 20
04

toolkit doc2md

Turns a PDF, a Word document, an HTML file, or a live URL into clean Markdown in one command — for notes, archives, or feeding content into something else that reads Markdown. 

$ toolkit doc2md https://example.com/article -o article.md

Install it

Pick your platform. Each one gets you the same four commands.

Linux / macOS

$ python3 -m pip install --user open-toolkit

Windows

> py -m pip install --user open-toolkit

Android (Termux)

$ pkg install python
$ pip install open-toolkit

From source

$ git clone https://github.com/YOUR_USERNAME/open-toolkit
$ cd open-toolkit && pip install -e .
